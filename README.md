# 🚀 Space Shooter Game

A 2D space shooter game developed with JavaScript and HTML5 Canvas for the Computer Graphics course project.

The player controls a spaceship and tries to survive by destroying incoming meteors. The game includes increasing difficulty levels, combo mechanics, particle explosion effects, animated backgrounds, healing planets, and large meteors that appear after Level 5.

---

# 🎮 Controls

| Key | Action |
|---|---|
| ⬅ Left Arrow | Move spaceship left |
| ➡ Right Arrow | Move spaceship right |
| Space | Shoot bullets |
| P / Esc | Pause / Resume game |
| M | Mute / Unmute music |
| Enter | Start game |
| Space (Game Over) | Restart game |

# ☄️ Difficulty System

The game becomes harder as the player progresses.

- Meteors spawn faster over time
- Meteor movement speed increases
- More meteors appear at higher levels
- After Level 5, large meteors start appearing
- Large meteors require multiple hits and deal more damage

---

# 🧠 Scoring System

| Action | Points |
|---|---|
| Destroy normal meteor | +10 |
| Destroy large meteor | +50 |
| Collect healing planet | +5 bonus score |

### Combo System
- Combo x2 and above → 5x score multiplier
- Combo x5 → 10x score multiplier

---

# ❤️ Health System

- The player has a health bar and multiple lives
- Meteors reduce health when they hit the player
- Missing meteors also causes damage
- Healing planets restore health according to the value written on them
- If health reaches zero, one life is lost
- The game ends when all lives are lost
